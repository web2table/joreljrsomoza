## GitHub Pages
1. Open **Settings → Pages**.
2. Choose **Deploy from a branch**.
3. Select **main** and **/(root)**, then save.
4. After the first deployment, add `joreljrsomoza.web2table.io` as the custom domain.
5. Configure the DNS record at Hostinger according to the GitHub Pages instructions and enable HTTPS when available.

This is a static site and does not require a backend, database, build workflow, or Hostinger web app slot.
